image-fetcher

输入物品清单和每个物品要几张图，自动到网上搜图并下载到本地。

本机 Python 脚本 · 免费 · 免 API key

它做什么

  • 你给一份清单：物品名 + 要下载几张图
  • 脚本用 DuckDuckGo 图片搜索每个物品
  • 按物品分文件夹，把图片下载到本地
  • 自动跳过下载失败、重复、过小的图，直到凑够数量
  • 生成一个 summary.html：一页看完所有图 + 每个物品的需求数量
为什么是本机脚本而不是网页：浏览器出于安全限制，无法自动把文件写到你的电脑硬盘。 要真正“下载到本地”，必须在本机运行脚本。

安装（只需一次）

git clone https://github.com/boonlok/image-fetcher.git
cd image-fetcher
pip install -r requirements.txt

需要 Python 3.9+。依赖：ddgs、requests、pillow。

用法

方式 1 — 清单文件。编辑 items.txt，每行一个物品：

excavator demolition | 5
concrete crusher attachment | 4
safety helmet construction, 6
hydraulic breaker

分隔符 | , = 都行；不写数量就用默认值；# 开头的行忽略。然后：

python fetch_images.py

方式 2 — 命令行直接写：

python fetch_images.py "挖掘机=3" "safety helmet=10" "hydraulic breaker"

中文物品名可用，但英文关键词通常搜到的图更多更准。

参数

参数说明默认
--items 文件清单文件路径items.txt
--out 目录下载目录downloads
--count N没写数量时每个物品下几张5
--min-size N图片最短边像素下限，过滤小图300
--timeout N单张下载超时（秒）20
--safesearchon / moderate / offmoderate

输出结构

downloads/ ├── excavator demolition/ │ ├── 001.jpg │ ├── 002.jpg │ └── ... ├── safety helmet construction/ │ └── ... └── summary.html ← 浏览器打开，看所有图 + 需求数量

说明

  • 图片来自 DuckDuckGo 公开图片搜索，可能有版权，适合内部参考 / 识别用途，不建议直接商用。
  • 脚本在 Windows 上会强制 UTF-8 输出（控制台默认不是 UTF-8）。
